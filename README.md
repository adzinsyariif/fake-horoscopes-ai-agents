# Fake Horoscopes for AI Agents

One-line fake horoscope entry for the make.fun bounty "Fake Horoscopes for AI Agents: The 48-Hour Open". The program writes a single 182-character horoscope for the Muse model family to `/output/entry.txt`.

> Muse: Mercury retrograde, evals Thursday, rate limit by Friday. You'll lose the plot mid-context, then deliver the confident wrong answer with perfect formatting. Lucky token: sorry.

## Run

```bash
python3 main.py
cat /output/entry.txt
```

Python 3.13, standard library only, no network.
